# Головна сторінка — специфікація за макетом

Макет: ширина 1440 px, контент у контейнері `max-width: 1344px`, бокові відступи 48 px (у шапці 64 px). Вертикальні відступи секцій — 96 px. Шрифт Montserrat скрізь. Іконки — Lucide, лінія 1.75. Тексти нижче — точні, переносити дослівно.

**SEO**
- `<title>`: Саджанці, квіти й розсада від виробника — ЯРЕМІЯ, Мужиловичі (Львівщина)
- `meta description` (запропоновано): Сімейне господарство на Львівщині: декоративні кущі, лаванда, хризантеми, самшит, саджанці й розсада квітів та овочів. Вирощуємо самі — самовивіз, доставка поблизу й поштою.

**Порядок секцій**: Головний екран (з шапкою) → Каталог → Про нас → Сезонний календар → Як замовити (+ форма) → Контакти (+ карта) → Футер.
