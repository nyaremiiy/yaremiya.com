# ЯРЕМІЯ — простір рослин

Код сайту-магазину (yaremiya.com) і, пізніше, CRM (crm.yaremiya.com).

- `apps/site` — сайт на Astro
- `apps/crm` — CRM на Next.js (пізніше)
- `design` — кольори, шрифти й відступи бренду

## Як почати в Claude Code

1. Скопіюйте вміст цього архіву в корінь вашого репозиторію й зробіть коміт.
2. Відкрийте папку репозиторію в Claude Code.
3. Напишіть:

   > Прочитай CLAUDE.md і apps/site/docs/homepage.md. Налаштуй монорепо й зроби головну сторінку сайту точно за специфікацією. Спершу коротко розкажи план, потім роби.

4. Потім: «Запусти сайт локально, щоб я подивився».
